## jsDelivr CDN 加速博客静态资源

### 背景
博客部署在 Cloudflare Pages（amigo-blog.pages.dev），国内访问 pages.dev 域名慢。主要卡顿来源：
- 首页视频 1.7MB（preload=auto 首屏强下载）
- 中文字体 zql.woff2 2.3MB + PingFangQiaoMuTi.ttf 3.8MB + AlimamaFangYuanTi.woff2 2.9MB

### 方案
将不变更的静态大资源（字体 + 视频）通过 jsDelivr 从 GitHub 仓库分发：
`https://cdn.jsdelivr.net/gh/q3190872366/amigo-blog@master/themes/Amigo/static/...`

### 改动文件
- `themes/Amigo/assets/css/style.css`：3 处 @font-face src → CDN 绝对 URL
- `themes/Amigo/assets/css/remixicon.css`：remixicon woff2 → CDN
- `hugo.toml`：headerMedia → CDN 视频 URL

### 线上验证
- 首页视频：jsDelivr ✓
- 4 个字体（zql/PingFangQiaoMuTi/AlimamaFangYuanTi/remixicon）：jsDelivr ✓
- 首屏仅剩 ~300KB（CSS+JS+favicon+avatar）走 Pages，大幅减负

## 分支统一（main → master）
- 仓库默认分支 PATCH 为 master
- 删除远端 main 分支
- deploy.yml push 触发分支修正为 master
- bot-src/index.js：workflow_dispatch 默认分支 'main' → 'master'
- bot 内容仓库写操作（uploadImage/updateContent/deleteFile）显式指定 `branch: contentBranch`
- getRepoConfig 新增 contentBranch 字段（默认 'master'）
- GitHub API DNS 被屏蔽（新加坡 IP 20.205.243.x），通过 `--resolve 140.82.121.5` 强制旧 IP 绕过
- SSH over 443（ssh.github.com）稳定，git push 全部走 SSH

## git push GitHub 网络方案
- 本沙箱 github.com:443 被墙，api.github.com DNS 被污染
- 解决方案：SSH over 443（~/.ssh/config Host github.com → ssh.github.com:443）
- 部署密钥：ed25519，已通过 API 添加为仓库 deploy key（read_only: false）
- API 可走 `--resolve api.github.com:443:140.82.121.5` 强制旧 IP
