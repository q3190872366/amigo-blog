## 本地后台服务（admin-local.mjs）

### 目的
后台所有写操作走 GitHub API，本地博客读本地 content/，两边不同步导致本地测试裂图。建本地后台服务让后台直接读写本地仓库，Hugo 热更新即时可见。

### 文件
- `scripts/admin-local.mjs`：Node 静态+API 服务（端口 8787）
  - `GET/PUT/DELETE /api/contents/{path}`：GitHub Contents API 本地实现
  - `GET /api/raw/{path}`、`GET /static/{path}`：直出文件（图片用）
  - 托管 static/admin/ 静态页面
- `static/admin/admin.js`：检测 `location.port==='8787'` 或 `?local=1` 进入 LOCAL 模式
  - `gh()` 改走本地 `/api/contents`
  - `imgRef()` 本地模式返回 `/static/posts/images/name` 或相对文件名
  - `upPrev()` 本地模式重写 img src，并加 onerror fallback 到公共目录
  - `doDeploy()` 本地模式直接提示不触发 GitHub Actions

### 已知坑
1. `serveStatic` 路由正则 `/^\/admin\/?/` 用 `\/?` 是可选，导致 `/admin.css` 被误吃成 `/.css` → 改用 lookahead `/^\/admin(?=\/|$)/`
2. `serveStatic` 把带前导斜杠路径传 `path.resolve` 当成绝对路径 → join 前 `replace(/^\/+/,'')`
3. `createServer((r,res)=>{...})` 回调里 `r` 是请求对象，`res` 才是响应 → 调用 `handleApiContents(r,...)` 等都应传 `res`
4. `(p.startsWith('/static/'))` 路由不能 `p.slice('/static'.length)`，会把 `static/` 剥掉 → 改成 `serveRaw(res, p)` 保留完整路径
5. PowerShell 杀进程在本沙箱不稳定，用 bash `netstat -ano | grep :8787` + `taskkill /F /PID` 更可靠

### 测试命令
```bash
cd E:/S3/boke && node scripts/admin-local.mjs  # 启动 8787
curl -s "http://localhost:8787/api/contents/content/posts"  # 验证 API
```

## 手机端编辑器编辑框消失问题修复

### 症状
手机端（390px 宽）打开编辑器：表单（标题/Slug/日期/作者/分类/标签/AI 评论/文件夹）正常显示，但表单和底部状态栏之间的编辑框（textarea）完全不可见，只剩 17px。

### 根因
1. 表单 `.ed-info` 在手机端高达 621px
2. `.ed-info` 有 `flex-shrink:0`（基础样式），不收缩
3. `#ed` 是 flex column 容器，高 775px
4. flex:1 的 `.ed-body` 被挤到 17px（仅 padding）

### 修复
手机端 (`@media max-width:900px`)：
- `.ed-info`：`flex:0 1 auto; max-height:45vh; overflow-y:auto`（可收缩，内部滚动）
- `.ed-body`：`flex:1 1 0; min-height:240px`
- `.ed-pane`：`min-height:200px`
- `.ed-wrap textarea`：`flex:1 1 0; min-height:200px`
- 背景统一米色 `#f5f1e8`，白色卡片用 `var(--card)`
- 清理重复覆盖规则（旧 `.ed-wrap{height:100%}` 覆盖了 flex 布局）

### 提交
- `5a9641a` fix(admin): 手机端编辑器编辑框不可见 — 表单 flex 收缩+滚动+最小高度

## jsDelivr CDN 加速博客静态资源

### 背景
博客部署在 Cloudflare Pages（amigo-blog.pages.dev），国内访问 pages.dev 域名慢。主要卡顿来源：
- 首页视频 1.7MB（preload=auto 首屏强下载）
- 中文字体 zql.woff2 2.3MB + PingFangQiaoMuTi.ttf 3.8MB + AlimamaFangYuanTi.woff2 2.9MB

### 方案
将不变更的静态大资源（字体 + 视频）通过 jsDelivr 从 GitHub 仓库分发：
`https://cdn.jsdelivr.net/gh/q3190872366/amigo-blog@master/themes/Amigo/static/...`

### 改动文件
- `themes/Amigo/assets/css/style.css`：3 处 @font-face src → CDN 绝对 URL
- `themes/Amigo/assets/css/remixicon.css`：remixicon woff2 → CDN
- `hugo.toml`：headerMedia → CDN 视频 URL

### 线上验证
- 首页视频：jsDelivr ✓
- 4 个字体（zql/PingFangQiaoMuTi/AlimamaFangYuanTi/remixicon）：jsDelivr ✓
- 首屏仅剩 ~300KB（CSS+JS+favicon+avatar）走 Pages，大幅减负

## 后台图片 CDN 与预览修复

### 问题
1. 手机端预览 tab 切换后是灰色空白
2. 图片上传后路径错误，博客无法显示
3. 后台图片没有走 CDN 加速

### 根因
1. `.ed-prev` 类名与 `swPane('preview')` 查找的 `ed-preview` 不匹配，导致 pane 没有 `.on` 类
2. `setMode` 直接设置内联 `display`，与 `.on` 类冲突
3. 图片插入的是相对路径或 `/static/...` 错误路径，主题 gallery 的 `Resources.GetMatch` 匹配失败

### 改动
- `static/admin/index.html`：预览 pane 类名 `ed-prev` → `ed-preview`
- `static/admin/admin.css`：同步修改 `.ed-prev` → `.ed-preview`
- `static/admin/admin.js`：
  - 新增 `CDN` 常量：`https://cdn.jsdelivr.net/gh/q3190872366/amigo-blog@master`
  - 新增 `imgCdnUrl(name, slug)` 生成 CDN URL
  - `insImgToEd` / `upMany` / `mgrUpload` 插入 CDN URL
  - `renderImgs` / `cpy` 媒体库复制 CDN URL
  - `newPost` 初始化时调用 `upPrev()`
  - `swPane('preview')` 自动调用 `upPrev()`
  - `setMode` 不再直接设置 pane 的 `display`，统一由 `swPane` 控制

### 图片 CDN URL 规则
- 当前文章 page bundle：`https://cdn.jsdelivr.net/gh/q3190872366/amigo-blog@master/content/posts/{slug}/{filename}`
- 公共目录：`https://cdn.jsdelivr.net/gh/q3190872366/amigo-blog@master/static/posts/images/{filename}`

### 验证
- 手机端预览 tab 正常渲染 marked 内容 ✓
- 编辑器中插入的图片 URL 为完整 jsDelivr URL ✓
- 主题 single.html 中 `findRE "^(http|/)"` 会跳过转换，直接使用 CDN URL ✓
