## 多页面后台拆分（发布动态独立页）

### 背景
单文件 `index.html` 改任何功能都要动整个文件，风险大。开始按页面拆分：
- 抽出共享代码到 `admin-core.js`（状态/认证/API/工具/Toast/CDN懒加载/图片压缩）
- 新建独立 `moments.html` 发布动态页（按截图设计）
- 首页 dashboard 加绿色"发布动态"入口

### 新增文件
- `static/admin/admin-core.js`：共享模块（被所有新页面引用）
- `static/admin/moments.html`：发布动态独立页
- `static/admin/moments.css`：移动优先样式（顶部栏、工具栏、文本框、图片标签、媒体库抽屉、桌面端居中卡片）
- `static/admin/moments.js`：页面逻辑（鉴权、格式化、图片上传、媒体库选择、发表）

### 踩坑
1. `<script src="..."><!-- --></script>` 里的 HTML 注释让浏览器只执行内联内容、忽略 src，导致整个脚本不加载 → 删掉 `<!-- -->`
2. `admin-core.js` 不能和 `head-init.js` 重复声明 `let _m=0` 等变量（`SyntaxError: Identifier '_m' has already been declared`） → 删掉 admin-core.js 里的 `_m/_c/needM/needC`，全部由 head-init.js 提供
3. 新页面用 `<a href="moments.html">` 跳转而不是 `go('moments')`，因为 `go()` 只在 index.html 的 admin.js 里

### 数据存储
- 路径：`content/posts/{YYYY-MM-DD-HHMMSS}/index.md`
- front matter：`title:"" / date:ISO / draft:false / type:moment`（可选 tags）
- 图片：上传到 `{slug}/` 目录，body 里用相对路径 `![](img-name.webp)`（与 Hugo page bundle 兼容）
- 从媒体库导入的图片：先 copy 到当前动态目录再插入正文（避免跨文章引用丢失）
